# PEANUT_BUTTER 独立研究

**Claude 的 PB 策略确实存在，复现有效；本轮最佳单品是它的自身均值回归变体，三日70,919 Coins。** 加到冻结 final_v4 得到393,514；加到尚未批准推广的 TELL 突破研究组合得到453,096。这是有限网格内最高有效基础回放，不是全局最优或官方成绩。

动态 PB–JELLY 版本单品收益65,177，低于最佳自身模型；但加到 TELL 组合后为447,354、最大单日回撤17,903.5，低于最高收益组合的24,859.5。因此保留一个较低样本回撤备选，不把它宣称为已证明的稳定新alpha。原final_v4、原TELL候选和所有先前研究均未修改，没有自动合并/推广/提交。

所有三个日期都已反复使用，是训练研究数据，不是新OOS。下文费用均0，实际spread、盘口深度、部分成交、pending承诺与延迟仍计入。每天从零仓位和零累计交易现金流独立重置；最大回撤是最大单日回撤。

## 2. 有限模型和执行修复

官方本地Wiki表规定PB50、JELLY50。主比较用PB50，25手仅作真实容量重跑，未线性放大低仓位利润。所有新模型只交易PB，JELLY仅为输入，组合内旧JELLY腿仍是唯一库存拥有者。

先登记13配置：自身D型信号5组（锚250/500/1000及入场1/1.5/2，一次改一个因素）、原25/50与修复25/去启动方差偏差/E型自身统计控制5组、关系模型3组。随后只追加两个同实现beta=0归因对照，明确是看完首轮后的消融，未搜索新阈值。再冻结压力、容量和组合评估。

- 自身最高模型：锚500、方差1000、warmup300、入场|z|≥2、退出0、信号年龄1000，仓位50。
- 动态level：仅用历史EW水平协方差/方差估计beta，fair=历史均值PB+beta×(当前J−历史均值J)。
- 动态return：仅用历史收益协方差/方差估计beta，fair=历史EMA500(PB)+beta×(当前J−历史EMA500(J))。两者beta半衰期1000，残差方差1000、warmup1000、入场1.5、退出0。
- 固定2.5只是旧J−0.4PB关系的反例，不是生成规律或官方权重。它三天全亏。

当前观测只在信号计算之后更新均值、beta和方差。新执行层使用当前对手价、实际顶层深度和同侧pending扣减；退出锁定target0，实际库存与挂单承诺清零后才重开，完成清零的同一次callback不反向入场。同timestamp重复返回记忆时发送空订单并保留原pending，不宣称平台任意重复提交均exactly-once。没有捏造期末强平。

## 4. JELLY 有多少真正增量

[原始报价及预测诊断](studies/data/report_v1/REPORT_CN.md)核对60,000条PB/J报价无错位。PB中位点差6、JELLY11，最优档中位深度均15。同刻收益相关约0.59–0.61，1/2/5观测领先相关绝对值≤0.02042，未见稳定领先。历史2000观测水平beta范围−0.193至1.783，也不支持固定2.5。

严格按历史前缀拟合、清除跨块标签后，EW level加入PB自身预测基线的h50/200/500 MSE恶化9.01%/10.04%/19.06%；return-beta恶化7.35%/9.41%/16.80%。线性自身基线也不总优于零变化预测，故这些MSE结果不能直接代替阈值持仓回测。

实际交易的精确消融：level38,630低于beta0的54,139；return65,177高于beta0的57,720，增量**7,457**。但三日增量分别**−3,431 /−1,576 /+12,464**，全由day0抵消此前负值；return还留下4,187未实现收益。mark多9,889，执行多亏2,432，成交多850单位。延迟下增量仅2,772（60,171−57,399）。因此不能说跨J信息稳定提升了每一天，也不能把单次正的总交易增量抹掉。
